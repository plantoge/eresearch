## Aturan UI yang Disarankan

### Komponen utama

Untuk setiap item telaah:

```text
┌──────────────────────────────────────────────┐
│ Pertanyaan                                   │
│                                              │
│ ○ Ya    ○ Tidak    ○ NA                      │
│                                              │
│ Komentar / Rekomendasi                       │
│ ┌──────────────────────────────────────────┐ │
│ │                                          │ │
│ │                                          │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

### Struktur data

Setiap item telaah sebaiknya mempunyai struktur:

```text
section
  └── item
       ├── question
       ├── answer: yes | no | na
       └── comment
```

Untuk pertanyaan yang memiliki pilihan tambahan, misalnya tingkat risiko:

```text
risk_level: low | medium | high
```

Untuk jenis penelitian:

```text
research_types:
  - intervention
  - observational
  - epidemiology
  - social_human_behavioural
  - secondary_data
  - case_study
  - genetics
  - other
```

Dengan struktur ini, form dapat dengan mudah diterjemahkan AI menjadi **database schema, Laravel/Livewire form, API request, validation rules, maupun UI component**.
